# Схема подключения

Питание всего — от USB ноутбука или пауэрбанка (5 В). Сеть 220 В не используется.

| Откуда | Куда (ESP32 DevKit) | Примечание |
|---|---|---|
| LD2410C VCC | 5V (VIN) | радару нужно 5 В |
| LD2410C GND | GND | |
| LD2410C TX | GPIO16 (RX2) | уровни 3,3 В, преобразователь не нужен |
| LD2410C RX | GPIO17 (TX2) | |
| WS2812 +5V | 5V (VIN) | не больше ~15 светодиодов, яркость ограничена в коде |
| WS2812 GND | GND | |
| WS2812 DIN | GPIO5 через резистор 330 Ом | резистор защищает первый светодиод |
| Фоторезистор | 3V3 → фоторезистор → GPIO34 | |
| Резистор 10 кОм | GPIO34 → GND | делитель напряжения: темнее = меньше значение АЦП |
| Конденсатор 470–1000 мкФ | между +5V и GND ленты | по желанию, сглаживает пуски |

```
          3V3 ──[фоторезистор]──┬── GPIO34
                                └──[10k]── GND

  LD2410C:  VCC─5V   GND─GND   TX─GPIO16   RX─GPIO17

  WS2812:   +5V─5V   GND─GND   DIN─[330R]─GPIO5
```

Для сдачи: сфотографировать собранную схему и, по желанию, нарисовать её от руки — фото кладём в `docs/wiring_photo.jpg`.
